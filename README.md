# AI Productivity Toolkit – Smart Prompt Engineering Assistant
## Project Overview
The AI Productivity Toolkit is a Python-based application that helps users create structured prompts for different AI tasks.
## Features
1. Zero-shot prompting
2. Few-shot prompting
3. Role-based prompting
4. Structured JSON prompting
5. Text summarization prompt generation
6. Text classification prompt generation
7. Email assistant prompt generation
8. Resume assistant prompt generation
9. Prompt evaluation
## Technologies
- Python 3
- Prompt Engineering
- Modular Python Programming
- VS Code
- Google Colab
## Project Structure
- main.py – Main application
- toolkit/ – Five AI assistant modules
- prompts/ – Prompt templates
- outputs/ – Saved generated prompts
- reports/ – Testing documentation
## How to Run
1. Install Python 3.
2. Open the project folder.
3. Run: python main.py
4. Select an option from the menu.
5. Enter the requested information.
6. Save generated prompts when prompted.
## Note
This version generates reusable AI prompts and evaluates prompt quality using rule-based checks. It does not currently connect to a live LLM API.
